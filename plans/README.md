## Findings considered and rejected

- Splitting all prompt dispatch out of the 2,686-line `ControlPlane` was rejected
  for this change. The class is intentionally the central session orchestrator,
  and a broad extraction would obscure the steering fix.
- Removing optimistic steering feedback entirely was rejected. It would delete
  state, but remote-host round trips would make submitted prompts visibly
  disappear. Plan 003 instead unifies the optimistic state.
- Named run profiles for text, review, automation, and interactive work were
  rejected. They create a second configuration layer that can drift from the
  calling service. Plan 005 makes each service pass its exact Solus tool array.
- Provider-native capability normalization was rejected for Plan 005. Claude
  and Codex built-ins remain provider-adapter details; only Solus-defined tools
  receive the neutral contract.
- Diff-comment action presets remain rejected for Plan 008. The existing inline
  comment form, queued-comments chip, and Diff action bar are reused in the file
  editor without another interaction layer.
