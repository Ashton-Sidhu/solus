# Stop simulators and emulators

In the desktop or web Devices pane, open the device list. Select the stop
button beside a running device, or select **Stop all** to stop the running
simulators and emulators on the selected Solus host. Stop all also includes
devices with open previews. Connected physical devices are excluded.

Confirm the action to stop the devices and close their previews. If a device
fails to stop, the list gives the reason and Solus continues with the remaining
devices. If an agent has control of a device, use **Take control** in its preview
before you retry.

In the native mobile app, open a device preview and use **Shut down device**
after you take control.
