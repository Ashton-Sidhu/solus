# Copy chat tables

On desktop and web, open **Copy table** below a table. Choose HTML, Markdown, CSV, or PNG. The PNG includes all columns, including columns outside the scroll area. The PNG option appears when the client can write images to the clipboard.

The desktop and web PNG uses the current table layout. Expand collapsed cells first to include their full text. The PNG can omit external images that the browser does not let Solus read.

On iOS and Android, touch and hold the table and choose **Copy as PNG**. This option also includes columns outside the scroll area. The menu keeps **Copy** for HTML and tab-separated text, and **Copy as Markdown**.
