# Claude Auto

The permission picker on desktop, web, and mobile shows when Claude settings
turn off Auto. The disabled option names the source: the project, your Claude
settings, or your organization's Claude settings. Open the picker again after
you change the setting.

If a session set to Auto starts in Claude's approval mode, the transcript shows
a notice. The session keeps its selected mode. You can select Supervised or
Auto-accept edits to use that mode on the next turn. Solus also applies its
permission policy.
