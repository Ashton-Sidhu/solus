# Prompt Stash

On desktop and web, press **Cmd+S** on macOS or **Ctrl+S** on Windows and
Linux to set aside the prompt in the active composer. Solus saves the text,
attachments, and references, then clears the composer. Wait for uploads to
finish before you stash a prompt.

With an empty composer, press the same shortcut to restore a single stash or
open the drawer above the composer. When the stash has saved prompts, the
bookmark in the Session actions row also opens the drawer. Select a prompt
to restore it or use its delete button to remove it. When you restore into
a composer with text, Solus adds the restored text below your draft.

Solus keeps the latest 20 stashes in the current desktop or browser profile,
separately for each account and organization. You can restore a stash in
another conversation. If it contains a file stored on a host, restore it on
that host. If an upload is missing or more than 24 hours have passed since
you stashed it, attach the file again or remove it before you send.
