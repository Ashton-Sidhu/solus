# Open a page from a snapshot

Snapshot images remain available after their browser page closes.

“Open in pane” checks the original host for the page. If the page is closed,
it opens the snapshot URL as a new browser page on that host. The new page is
live content; it can differ from the saved image. Reopening uses the default
browser profile because snapshots do not store the original profile.

The snapshot gallery closes its image viewer after the page is ready to open
in a pane. A host or navigation error appears as a notification and leaves the
image viewer available. These shared controls apply to desktop, web, and mobile.

Snapshots fit inside the image viewer on open. Both image dimensions are
bounded by the frame, so tall images remain fully visible. Clicking to zoom
shows the capture at its original page width and permits scrolling. Selecting
another frame resets zoom. A single snapshot card also shows the full image
in its collapsed preview.
