# Current session actions

On desktop and web, press `Cmd+K` or `Ctrl+K` while a conversation has focus. The **Current session** group shows the actions available for that conversation. If two conversations are open, the actions apply to the pane with focus.

Use **Snooze session** to choose a preset or set a date and time. You can also search for a preset, such as **Snooze tomorrow**. Use **Wake session now** to end a snooze. **Complete session** marks the session as completed. Use **Reopen session** to make it active again. **Archive session** removes it from your list. Open an archived conversation from session search and use **Restore session** to return it to your list. Pin and archive actions apply to your own list.

On mobile, use the session list menu for pin, snooze, wake, settle, un-settle, and archive. Use the Archive screen to restore an archived session.
