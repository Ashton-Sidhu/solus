# Session search

Put straight or curly double quotes around the full query to find an exact phrase. For example, `"fix the sidebar"` finds those whole words next to each other, in that order, in one name or message. An unquoted query or a query with an unfinished quote uses the usual word search.

You can still paste a branch name or a pull request reference such as `#482`, `pr 482`, or a pull request link in quotes. The `search_sessions` agent tool also takes quoted phrases.
