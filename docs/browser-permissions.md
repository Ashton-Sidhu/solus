# Camera and microphone access in the desktop browser pane

When a site asks for the camera or microphone, Solus shows the site's origin and the devices it requests. **Block** is the default. On macOS, choose **Allow** before Solus asks for system access. If the system blocks a device, check its privacy settings.

Solus keeps each answer in memory for the site origin, device, and browser profile partition. To reset these answers and sign out of sites in that profile, use **Clear browser data** in the browser toolbar. Quitting Solus also resets the answers.
