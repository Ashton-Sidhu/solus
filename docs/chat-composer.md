# Rich text in the chat composer

Paste or drop linked text into the chat composer to keep the link label and
destination as a Markdown link. This works for HTTP, HTTPS, and email links
when the source supplies both HTML and matching plain text. The plain text
supplies the spacing and line breaks.

Use **Paste as Text** to insert the original text. Text copied from an HTML
code sample stays literal. Text pasted into Markdown code also stays literal.
Solus reference chips and media use the existing clipboard rules.

On mobile, rich text needs a native paste or drop that supplies both formats
in one item. Some keyboards and apps supply only plain text.

On desktop and web, drag a draft from the session sidebar into the composer
to insert a session chip. Click the chip to open the draft. When you send a
message with the chip, the agent gets the draft text if the draft is still
unsent. After the draft starts, the chip points to its conversation.
